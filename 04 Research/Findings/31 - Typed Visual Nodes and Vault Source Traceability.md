# Typed Visual Nodes and Vault Source Traceability — Adopted Finding

The existing visual registry remains the payload authority. A typed graph index now points to those payloads and to a separate catalog of vault sources. Scene compilation selects a bounded subgraph; renderer instructions and source trace remain separate outputs.

This is a production architecture decision only. It establishes no story canon.
