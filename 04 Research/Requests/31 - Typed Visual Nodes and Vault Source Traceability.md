# Research Request — Typed Visual Nodes and Vault Source Traceability

## Story question

What minimum graph structure lets the compiler turn vault knowledge into image instructions without losing source, authority, status, or unresolved boundaries?

## Scope

Model existing visual entities as typed graph nodes pointing to existing registry payloads and vault sources. Do not copy the whole vault into a second database. Distinguish story sources, production rules, approved visual decisions, research, and external renderer documentation.

## Required output

- Node, edge, source, authority, and status vocabulary
- Rules for payload references instead of duplicated facts
- Source-trace format kept outside renderer context
- Initial graph covering Sylvan, Samuel, appearances, wardrobe, eras, environment, manifestations, rejuvenation, style, composition, and renderer
- Validation and regression requirements

## Development gate

The graph must validate every node, edge, payload pointer, and vault source; a source trace must never leak into the clean renderer packet.
