# EG-10: Build the target substitution

## Purpose

Turn Samuel's target assignment into a traceable operation rather than a vague claim of religious influence.

## Established

Samuel does not write the prophecy. He tells Konrad, Aiden, and other leaders that Sylvan is the prophecied villain. He uses altered-reality controls, selected records, intermediaries, timing, and staged confirmation to make that identification appear independent and sacred.

Source: [[01 Sessions/Daily/2026-09-19 - Existing Prophecy Endgame Expansion]].

## Four possibilities

1. **Converging signs:** several channels repeat the same identification because Samuel has access to each one.
2. **Edited provenance:** genuine old material is paired with a false account of Sylvan's actions.
3. **Permission as proof:** a system response is presented as sacred confirmation even though Samuel arranged the access condition.
4. **Manufactured witness:** a trusted intermediary sincerely repeats a conclusion Samuel engineered upstream.

## Central author gate

Which three apparently independent confirmations identify Sylvan, how did Samuel influence each one, and what shared trace proves that the convergence was manufactured?

## Scene test

The leaders receive enough evidence to make their decision understandable, while the audience can later reconstruct the exact point at which Samuel entered the chain.

## Adversarial test

If Samuel merely announces the target, Konrad and Aiden appear passive. If the evidence is perfect, their later discovery has no plausible opening.
