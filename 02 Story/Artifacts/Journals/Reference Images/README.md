# Journal Reference Images

Store only author-approved journal-specific references here. Candidate outputs stay outside the durable reference library until approval.

Recommended per-character set:

- `<id>-handwriting-sheet-v1` — alphabet, numerals, signatures, phrases, corrections, arrows, and emotional states;
- `<id>-diagram-sheet-v1` — maps, trees, timelines, figures, symbols, and marginalia;
- `<id>-cover-v1` — object exterior and ownership marks;
- `<id>-interior-spread-v1` — paper, ruling, margins, numbering, inserts, and typical use;
- optional material/prop references with a written scope.

For each file record status, scope, creator/tool, date, source prompt, dimensions, checksum, and warnings in the character profile. Do not copy approved identity portraits here; link to the existing visual registry.
