# Thread Ledger Template

Status: working template (Story Development System, 2026-11-21). Every planted thread gets one row when planted. Nothing is planted without a row; no row is allowed to die silently. If a payoff is abandoned, the row is marked rejected with the reason, never deleted.

## Rules

- A thread planted by impersonation or supplied interpretation names the true source, not the apparent one.
- A thread that another thread depends on names its dependency in the thread text.
- At each gate, the ledger is read whole: any thread whose latest payoff point has passed without landing is escalated to the author as a decision, not quietly extended.
- The who-knows-what-when matrix is drawn from this ledger plus the character dossiers; when the two disagree, the ledger is corrected first and the matrix redrawn.
