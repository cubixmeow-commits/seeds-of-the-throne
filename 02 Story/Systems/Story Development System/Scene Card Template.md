# Scene Card Template

Status: working template (Story Development System, 2026-11-21). One card per scene, completed before drafting. A scene that cannot fill the "what this scene does" line is filler and is cut or merged.

- **Scene:** (number and working title)
- **Position:** (Beginning / Middle / End, sequence, order in plot)
- **Fabula position:** (where it truly sits in the chronology, if different)
- **Synopsis:** (one paragraph, plain account)
- **Point of view:** (whose eyes; what they can know at this point, and no more)
- **Place:** (where, narrowed as the book narrows)
- **Strand:** (which narrative line this belongs to)
- **What this scene does:** (collapse an illusion / increase uncertainty / narrow geography / block information; name which, and what exactly changes)
- **Threads planted:** (ledger IDs)
- **Threads paid off:** (ledger IDs)
- **Knowledge changes:** (who learns, believes, or loses what; matrix rows touched)
- **Status:** (established / working / proposed / unresolved)
