# Continuity audit matrix

Check only rows relevant to the task.

| Domain | Questions |
| --- | --- |
| Identity | Are names, relationships, roles, lineage, and pronouns consistent? |
| Chronology | Do ages, durations, event order, travel, and technology coexist? |
| Knowledge | What is true, believed, suspected, concealed, or impossible for each character to know? |
| Causality | Does each major effect have a sufficient prior cause and access path? |
| Agency | Does the person make a choice, or does the outline force an unexplained action? |
| Systems | Do Luminai, Daemons, containment, influence, synthetics, and story functionality obey current limits? |
| Evidence | Can the revelation be proved through records available at that point? |
| Theme | Does framing preserve development versus control and avoid importing faction ideology? |
| Status | Are established, working, proposed, unresolved, and rejected claims represented accurately? |
| Public boundary | Does public material expose private development, unsafe analogies, or unintended spoilers? |
