# Session note pattern

```markdown
---
type: development-session
status: active
date: YYYY-MM-DD
topics: topic one, topic two
---

# Session title

## Question explored

## Existing constraints

## Possibilities considered

## Author decisions

## Current working direction

## Unresolved questions

## Vault impact
```

Omit empty sections. Quote the author only when exact wording matters. Use plain summaries otherwise.
