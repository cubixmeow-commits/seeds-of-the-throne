# Lean Composition Capability Matrix

## Author direction

Design the Composition Engine so it selectively combines useful capabilities from existing writing systems while using a reasonable amount of model usage.

## Result

The proposed design is recorded at [[07 Coordination/Authoring System/05 - Prose Capability Matrix and Usage Routing]]. It uses one default model pass, deterministic checks first, risk-triggered specialist escalation, bounded context, and a maximum revision budget. It does not run every available writing skill against every scene.

## Governing constraint

Quality is measured against author approval and story integrity, not number of agents, critiques, or tokens consumed.

## Author decision — first vertical slice

The author approved the outcome-presentation confrontation as the first vertical-slice scene. Samuel attempts to offer Sylvan a customized version of the bargain that trapped Konrad while Konrad's inner circle can compare Samuel's claims with reality.
