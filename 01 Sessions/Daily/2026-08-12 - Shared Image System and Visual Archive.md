# Shared Image System and Visual Archive

## Established visual identities

The older crowned man in the supplied red-and-gold reference art is now the established visual identity for **Samuel Franklin**. The younger dark-haired and bearded man is the established visual identity for **Sylvan Elaria**.

Clean individual identity masters were generated for each character. They replace the older paired images as primary identity references because they contain one unobstructed subject, no competing face, and no embedded story labels. The paired images remain valuable supporting references for composition, wardrobe, palette, symbols, and the red-versus-gold conflict.

Each identity set now also includes a straight-on front view and a strict 90-degree left-side profile. The minimum canonical reference pack for an active character is therefore front, profile, and front three-quarter. The front view locks width, eye spacing, hairline, and symmetry; the profile locks forehead, nose, lips, chin, ear, hair volume, beard, crown or collar, and the silhouette that frontal imagery cannot show.

Some older supporting images identify the crowned man as George or use the obsolete term Lumina. Those labels are not current story authority. Agents must ignore embedded text in those files. Current terminology remains **Luminai**.

## Shared production system

The new `create-seeds-images` skill stores:

- a machine-readable visual registry;
- locked Samuel and Sylvan identity descriptions;
- the dark gothic archival science-fantasy style;
- the black, crimson, antique-gold, and parchment palette;
- reference priority and SHA-256 checksums;
- prompt-packet generation for Gemini and other image models;
- drift warnings and an approval scorecard;
- a character-record template for adding the rest of the cast.

Generated images do not establish story canon. New artwork remains a candidate until deliberately approved. An unapproved output may not become the sole reference for later generation because repeated reuse would turn small errors into permanent character drift.

## Public atlas

A new visual archive page presents the two canonical identity masters, the project color grammar, supporting story art, and a simplified version of the production workflow. The public page shows approved results while the vault retains prompts, checksums, provenance, and internal consistency controls.
