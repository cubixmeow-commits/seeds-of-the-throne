# Failure Modes

Add an entry only when a failure occurs in a real run. Update role instructions or the quality bar when the same failure recurs.

| ID | Failure | First seen | Recurrences | Current countermeasure |
|---|---|---|---:|---|
| F-001 | Proposal silently converts an unresolved idea into canon | anticipated from vault authority rules | 0 | Require authority labels and three author gates |
| F-002 | Architect adds a new faction, technology, or character instead of using existing material | anticipated from completion goal | 0 | Existing components first; expansion must be justified |
| F-003 | Critic rewrites the unit while pretending to grade it | anticipated from Gauntlet design | 0 | Critics diagnose; Integration Editor repairs only authorized issues |
| F-004 | Loop produces more notes without closing a story gap | anticipated from prior vault growth | 0 | Classify every run and prioritize close-gap work |
| F-005 | Technology solves causality through unexplained capability | anticipated from world rules | 0 | Continuity critic checks capability, permissions, cost, and hard limits |

- **Run:**
- **Observed behavior:**
- **Why it reduced quality:**
- **Role or stage responsible:**
- **Countermeasure tested:**
- **Result:**
