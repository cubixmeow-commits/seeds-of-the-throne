# Weekly Synthesis Configuration

## Modes

| Mode | Use | Core reports | Optional modules |
|---|---|---|---|
| Standard | normal weekly reset | all 10, concise | none by default |
| Deep | substantial capacity remains | all 10, expanded | choose 1–2 |
| Exhaustive | deliberate end-of-cycle use | all 10, full | all 3 if evidence supports them |

## Retrieval scope

Always read `START HERE.md`, `03 Context/CURRENT.md`, `03 Context/RULES.md`, `03 Context/OPEN-QUESTIONS.md`, `07 Coordination/CURRENT-PICKUP.md`, `07 QA/Decisions.md`, `07 QA/Contradictions.md`, and the prior synthesis manifest if one exists.

Then inventory, without treating all as equal authority:

- files changed since the last synthesis;
- active Story Units, runs, and brainstorms;
- implicated character/system/event notes;
- TODO/QA changes;
- journal/evidence registries;
- public drafts only for extraction and spoiler review;
- research only where it bears on a live mechanism.

For a first run, use a full-vault inventory but summarize sources before analysis. Do not dump raw files into every critic pass.

## Authority order

1. latest explicit author decision;
2. recorded decisions;
3. current context;
4. status-labeled compiled story notes;
5. dated sessions;
6. advisory research and non-canon exploration.

A later date alone does not outrank an explicit decision. Report conflicts; do not flatten them.

## Priority scoring

Score 1–5 for causal leverage, downstream blockage, character importance, evidence/setup urgency, and author-decision readiness. Subtract 1–5 for assumption cost. Use the score as a recommendation, not authority.

## Queue classifications

- **BUILD NOW:** sufficiently established/working and structurally ready for a Story Unit, sequence, scene specification, or approved vault task.
- **BRAINSTORM NEXT:** important but blocked by an author decision, missing alternatives, research, or mechanism.
- **LEAVE OPEN:** ambiguity currently creates value or the dependency is too remote to justify work.

## Stop rules

Stop expanding a branch when it reaches a load-bearing author choice, source-authority conflict, missing mechanism that needs research, dedicated active brainstorm boundary, or unsupported canon proposal. Produce the exact next question instead.

## Public boundary

Public-development ideas must label spoiler risk and source authority. Never expose private development, unresolved accusations as fact, raw transcripts, or real-person analogies.
