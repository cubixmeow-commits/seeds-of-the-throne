# Weekly Synthesis Runs

Create one dated folder per run and do not overwrite prior weeks. Copy the manifest and selected templates, record the comparison cutoff, and link the final queue to any Story Loop runs it initiates.

Dated queues and ranked-question reports are analysis history, not parallel author TODO lists. Every run must reconcile them into one author-approved completion checklist, then update `CURRENT-COMPLETION-TODO.md` to point at it. If no checklist change is approved, record an explicit no-change decision and keep the existing pointer.
