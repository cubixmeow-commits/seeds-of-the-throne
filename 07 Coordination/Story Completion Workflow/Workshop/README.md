# Story-development workshop

Twenty decision packets address the missing causes in this story. Eighty alternatives began as non-canon proposals. Modules 01 through 06 are now author-accepted; later gates remain open. No story task has been marked complete through the workshop.

## Start without losing the active thread

The active execution gate remains **SC-010 Question 7**. This workshop expands the existing workflow's decision support. It is not another TODO list. Preparing all modules is authorized; switching the author-led execution order remains an explicit choice.

For a short mobile session: choose one packet, read its central gate, write an answer, and export Markdown. For a desktop session: review sources and prerequisites, compare alternatives, run the scene and adversarial tests, and record acceptance only after the author confirms the restatement.

## Persistence and authority

Browser answers are local drafts on that browser and origin. They are not synchronized between sites or devices, and clearing browser storage can remove them. Export produces a Markdown file; importing a previous export restores the text for further work. No browser control writes to the vault, creates a canon decision, or sends data to an AI provider.

To integrate: place the exported answer in a dated session, restate it exactly, obtain author acceptance, update the current task and QA decisions, then update the affected canonical notes. Rebuild the websites with `python3 scripts/build_story_sites.py`.

Keep private answers out of a public repository unless the author has reviewed them for publication. The existing Explorer is public and read-only; spoiler disclosure is not access control.
