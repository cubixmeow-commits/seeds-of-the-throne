# Source Photos

Store lightweight, GitHub-friendly previews of source photographs here. Full-resolution originals stay outside the repository.

- Target roughly 50 KB per preview; use JPEG with a longest edge around 768 pixels.
- Record the original filename, native dimensions, checksum, and known external path in the episode record.
- Record the preview dimensions and checksum separately.
- Do not claim the preview preserves original metadata.
- Do not infer subject, location, or capture date when metadata and author confirmation are absent.
- Generalize or withhold sensitive wildlife locations when requested.
- Generated images and compressed previews never replace the full-resolution source as factual evidence.
