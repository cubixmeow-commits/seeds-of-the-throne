# Drafts

Store small JPEG previews of generated image candidates, caption drafts, and alt text here while they await author approval. Keep production-resolution masters outside the Git repository and record their checksums when available.

A polished draft is not approved or published. Preserve version numbers and record which candidate the author selects. Target roughly 50 KB per preview with the selected aspect ratio preserved and the longest edge at 768 pixels. Do not force drafts into a default portrait shape.
