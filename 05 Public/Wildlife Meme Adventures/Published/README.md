# Published

For each published Wildlife Meme Adventures episode, preserve:

- a small GitHub-friendly preview of the exact final image;
- the full-quality master dimensions, SHA-256, and external provenance;
- exact published caption and alt text;
- publication timestamp;
- X post URL;
- any meaningful post-publication correction or lesson.

Publication requires explicit author authorization. Approval to create a draft is not approval to post it.

Do not publish the compressed vault preview when a production-resolution master is available. The vault copy is for reference and repository portability.
