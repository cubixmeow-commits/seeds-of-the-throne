# Seeds of the Throne

This vault is persistent working memory for developing the story. It preserves the order in which ideas develop while also maintaining compact summaries of the current story.

## Start each session

1. Read [[03 Context/CURRENT]].
2. Read whichever of [[03 Context/CAST]], [[03 Context/WORLD]], or [[03 Context/STORY]] applies.
3. Check [[03 Context/OPEN-QUESTIONS]].
4. Record new work in `01 Sessions/Daily/` before updating compiled story notes.

## Shared methods

Reusable AI workflows live in [[skills/README|skills]]. Review the catalog and load only the skill that matches the current task. Skills guide process but never override the author, establish canon, or silently resolve uncertainty.

## Memory layers

- `01 Sessions/` — chronological development memory; exploration and contradiction are allowed.
- `02 Story/` — compiled notes about characters, systems, groups, environments, reveals, and storyline.
- `03 Context/` — the smallest useful briefing for a new GPT session.
- `04 Research/` — research requests, reports, and extracted findings. Research is advisory, never canon by itself.
- `07 QA/` — contradictions, decisions, migration records, and unresolved problems.

## Authority

The author's direct statements and decisions control the story. GPT develops, organizes, questions, and maintains continuity. Claude performs assigned research only. See [[03 Context/RULES]].
